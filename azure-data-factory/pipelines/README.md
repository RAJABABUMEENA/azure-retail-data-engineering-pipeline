# Azure Data Factory Pipeline Exports

This project used four deployed ADF pipelines:

- `PL_Initial_Load_Customers`
- `PL_Initial_Load_Metadata_Driven`
- `PL_Incremental_Load_Transactions`
- `PL_Master_Retail_ETL`

The genuine ADF JSON exports are not included because they were not provided as files. Do not replace them with fabricated exports.

To complete this folder, export each deployed pipeline from Azure Data Factory and add:

- `PL_Initial_Load_Customers.json`
- `PL_Initial_Load_Metadata_Driven.json`
- `PL_Incremental_Load_Transactions.json`
- `PL_Master_Retail_ETL.json`
